# 📸 Moment Capture App

Project foto sederhana berbasis web ini dibuat untuk kebutuhan **case interview** di **PT Casa Arta kreasi (Volab)**.  
Dibangun menggunakan **ReactJS**, **TailwindCSS**, **ViteJS**, dan **TypeScript**.

---

## 🚀 Tech Stack

- **Framework**: ReactJS  
- **Bundler**: ViteJS  
- **Styling**: TailwindCSS  
- **Language**: TypeScript  
- **Rendering**: Client Side Rendering (CSR)  

---

## 📦 Third-Party Libraries

- **react-dom**  
- **react-router-dom**  
- **react-webcam**  

---

## ⚙️ Cara Menjalankan

Clone repository ini dan install dependencies:

```bash
git clone https://github.com/username/moment-capture-app.git
cd moment-capture-app
npm install

```

```bash
# Development server
npm run dev
```

```bash
# Build untuk production
npm run build
```

```bash
# Preview hasil build
npm run preview
```
